# MorrowCache launch video kit

Editor-facing pack for the X/Reddit mute launch video. Motion language is locked to `refs/peak-ref.mp4` — continuous morphs, hold→punch, invert-pill type, vertical reels, odometer counters, in-place UI expand. See [MOTION.md](MOTION.md) and [FLOW.md](FLOW.md).

Zip: `docs/MorrowCache-launch-video-kit.zip` (sibling of this folder).

## Quick start

1. Watch `refs/peak-ref.mp4` once. Internalize the moves in MOTION.md.
2. Open FLOW.md — beat table is the cut list.
3. Drop plates from `stills/generated/` and `brand/` into CapCut / Premiere / Resolve.
4. Use `footage/demo-vhs.*` only as install proof inset.
5. Burn captions from `captions/*.srt` or SCRIPT.md if needed.
6. Export **15s hook** + **~35s master**. Mute picture; optional synth bed.
