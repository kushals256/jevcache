# Peak motion grammar

Reference: `refs/peak-ref.mp4` (~37.5s). Steal the **moves**, not the product.

## Laws

1. **Almost no hard cuts.** Soft morph / expand / dissolve / reel. If you feel a whip pan, undo it.
2. **Hold → punch.** ~60–70% of time is a static hold. Energy lives in 0.3–0.8s bursts.
3. **Beat lock.** Quiet open (~0–3s). From ~5s, picture punches on ~0.60s intervals (~100 BPM).
4. **One accent.** Hit-blue `#6ba3ff` plays the role orange plays in the ref. Everything else is ink / bone / muted gray on black.
5. **Dot-grid void.** Black field + fine point grid + faint top glow under floating UI.

## Signature moves

| Move | Feel | Use for Morrow |
|------|------|----------------|
| Spark stroke-draw | Accent point traces logo, then fill | Brand open |
| Invert-pill wipe | White rounded rect slides; word flips black-on-white | *intent* / *HIT* / *call* |
| Vertical noun reel | One line slot swaps strings with blur/ghost; anchor below stays | Paraphrase cycle |
| Odometer / slot | Digits roll into hero number; accent on unit | 2817 → 423 → 6.7× |
| Blurred field | Dense low-opacity label cloud behind number | Latency money shot |
| In-place UI expand | Glass bar → click → panel grows down (no cut) | baseURL → TraceTheater |
| Live UI ticks | Progress / SPEED / status update while camera holds | HIT panel settle |
| Feature board | Left eyebrow+headline+one line; right floating UI/schematic | Jaccard / refuse |
| Path spark | Accent orb travels a dashed connector | Fail-open / process |
| Quiet settle | Score drops; lockup holds | End card |

## Easing

- Snappy ease-out / expo for punches (pill wipe, reel swap, digit land).
- Softer ease for expands and feature crossfades.
- No constant camera shake. No stamp slam. No crash zoom as default.

## Anti-patterns (do not)

- Whip-pan desk / dual receipt slam as the primary language
- Always-moving camera
- VO / talking head
- Purple glow stacks, pill-cluster clutter, multi-card hero
