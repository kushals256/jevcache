02

Routers pick a model. MorrowCache decides whether to call one.

App MorrowCache HIT · cached answer MISS · upstream, then store
  • Exact key first. Identical prompts never reach the model twice.
  • Same-intent second. A paraphrase can reuse the stored answer.
  • Freshness can still refuse a stale “latest.”

03

What it refuses to be

Not cosine. Calibrated same-intent.

Not a router. Your model stays your model.

Not magic. Prefer a miss over a wrong hit. Streaming and tool calls bypass.

06

Questions

Do I need OpenRouter?

For cloud Jev, yes. For local Kev or Laya, no — not for admits. Upstream chat still needs a model key unless you mock it.

Does it run locally?

The proxy always does. The adjudicator can too, on a System One server you run yourself.

Streaming and tools?

Bypassed in this version. Those calls go straight upstream and are not cached.

Will it ever return a wrong hit?

Possible. Raise the intent threshold or run shadow mode while you validate. We do not claim zero false positives.
